# 小黑板 · 重点难点

基于保利威观看页 SDK 的直播课堂扩展。学员直播中一键「划重点／记难点」，课后回看知识点；运营查看难点报告，核对 AI 草稿、选择素材库视频或 PDF，发布给该难点全部反馈学员。

观看页品牌为「自在课堂」。“小黑板”是观看页中的个人重点难点入口。代码保存在 GitHub，演示在本地运行，不要求部署线上服务。

## 本地运行

需要 Node.js 22.13+（使用内置 SQLite）、npm，以及可访问保利威和模型接口的网络。

```sh
npm ci
cp .env.example .env
# 按下方说明填写 .env
npm run dev
```

- 观看页：http://127.0.0.1:4317/watch
- 运营后台：http://127.0.0.1:4317/admin

`.env` 需自行填写，不随代码提交：

| 配置 | 用途 |
| --- | --- |
| `POLYV_APP_ID`、`POLYV_APP_SECRET`、`POLYV_CHANNEL_ID` | 具有观看页 SDK、录制、字幕和素材库权限的保利威测试账号与频道 |
| `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` | 兼容 Chat Completions、支持图片输入与 JSON 输出的模型接口 |
| `ADMIN_PASSWORD` | 本地管理口令；不填则启动时随机生成并打印 |
| `SESSION_SECRET` | 随机长字符串，用于登录签名；固定后重启可保留浏览器身份 |
| `FFMPEG_PATH` | 可选，自行安装的 FFmpeg 路径；Apple Silicon 可使用项目可选依赖 |

密钥仅由服务端读取，不写入 `VITE_*` 变量。仓库不包含测试账号凭据、课程视频、本地数据库或学员记录；首次运行需使用自己的测试频道，建立直播场次并产生标记。保利威域名白名单及功能权限需按账号实际配置确认。

## 演示主流程

1. 在保利威测试频道开启直播或配置好的伪直播，观看页进入真实课堂
2. 学员点击「划重点／记难点」，5秒内可撤销；直播中不展示本场新增记录
3. 直播结束且回放、字幕就绪后，同步课程素材并生成难点报告
4. 运营进入「补充讲解」，核对 AI 草稿，可选择素材库视频或 PDF，确认后发布给该难点全部反馈学员
5. 学员点击「小黑板」，查看跨场次个人记录；原课回看、视频和 PDF 均单独打开预览

发布仅执行一次，第一期不支持修改、覆盖或追加。历史演练接口和固定数学样例仅用于自动化测试，当前观看页不提供本地演练入口。

## 技术组成

- 前端：TypeScript、Vite，保利威观看页 SDK v2.20.0
- 后端：Node.js、Express，服务端签名调用保利威开放 API
- 存储：本地 SQLite；运行数据位于 `data/`
- 课程素材：保利威录制 MP4、SRT 字幕、素材库视频与 PDF
- 关键帧：本地 FFmpeg 从回放抽取，未使用直播截图接口
- AI：外部模型理解字幕和关键帧，生成片段概述、可能难点与对应解释草稿；当前已验证模型为 `deepseek-v4.1-flash-1017`
- 回看和预览：原生视频播放器及浏览器 PDF 预览

## 验证

```sh
npm test
npm run build
# 配置真实账号后，按需执行只读接入检查
npm run check:integration
# 按需调用模型验证，会产生模型调用费用
npm run check:ai
```

`npm run build` 用于类型检查和前端构建，不是完整生产部署命令。

## 当前边界

- 已验证真实 SDK 播放、回放字幕查询、课程 AI 报告、独立回看定位和素材视频预览；PDF 还需用实际发布资料验收
- 后端提供主动查询同步；录制完成、字幕完成回调的接收与签名校验已实现，但公网送达未完整验证。本地 `127.0.0.1` 无法直接接收公网回调
- 时间定位依赖录制起点和观看延迟；未校准场次保留估算质量信息，不承诺精确对齐
- 使用连续单段 MP4；不支持多段自动拼接及复杂循环、裁剪时间轴。短课处理限制为300MB、最多12张关键帧
- 目前只验收视频布局和容器全屏，未完成三分屏、PPT 独立流、手机原生视频全屏与多人聊天实测
- 素材由运营手动选择；不做题库、信息流、理解效果反馈或发布后版本管理
