# 小黑板 UI 与交互优化

本轮只调整现有主流程的呈现与操作，不更改标记、发布、权限或后台配置规则。

## 页面任务

- 观看课堂：课程视频优先，讨论在侧边；更多展开小黑板，记录后5秒内可撤销
- 我的重点难点：重点/难点两个页签，片段内容、课程时间、回看与已确认的补充内容容易辨认
- 难点报告：先选频道与场次，再筛选未发布/已发布，逐段查看讲解与反馈人数
- 补充讲解：课程依据与解释对照，选资料和接收人，预览后可发布；发布规则不变

## 设计基线

原生HTML控件，沿用现有TypeScript工程。品牌蓝#3F76FC；正文黑色80%、次文60%、辅助40%。字号12/14/16，行高18/22/24，字重400/500；间距4的倍数，主要分组16/24/32；控件圆角4、容器8。浅色背景、白色主体。按钮最小36px，焦点清晰、状态有文字、不堆装饰或指标卡。

## 本轮调整

- 报告状态筛选直接可见，并显示数量；增加真实片段缩略图，强化课程时间与行内主动作
- 编辑区减轻大图占比，支持放大；难点依据按需展开，解释保留编辑能力，提供学员视角预览
- 返回列表保留筛选和滚动位置；刷新、弹窗、错误和禁用状态给清晰反馈
- 观看页、记录弹层与后台统一排印、控件、留白、空态；记录页签展示数量，隐藏技术场次标识
- 本轮不新增后台规则或服务端发布能力，不更改聊天室策略
