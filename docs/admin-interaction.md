# 后台交互调整

目标：运营进入后台能知道当前场次处于哪个阶段，找到多人没懂的片段，核对补充内容并一次发布。

- 报告列表是起点：频道、场次 → 难点时间/讲解内容/人数/发布状态 → 补充讲解
- 汇总数字与片段列表同屏，不让运营在“汇总/明细”两套入口中选择
- 编辑是独立工作界面：左侧原讲解与理解难点，右侧补充解释和材料；底部固定接收范围与发布按钮
- 默认发给全部反馈学员，可单独调整。保留未提交的本页草稿，返回列表后再进入不清空
- 发布成功后停在明确的只读结果，可返回报告；不自动跳到别的视图
- 演练控制和技术接入放单独弹层。直播中/未生成/分析中/失败/已生成状态各给清楚的下一步
- 维持一次发布、无发布后修改的业务边界

原生HTML控件，沿用品牌蓝#3F76FC，正文14/22，分区标题16/24，辅助12/18；白色业务主区、浅灰表头，边距16/24，编辑区单一发布主操作。
